# Archive

Read the [work protocol](../README.md) before archiving or resuming work.

Use `YYYY-MM-DD_<task-ref>_<slug>/`, omitting `<task-ref>_` without a
filesystem-safe task ID. The date is when the folder is archived. Keep this
directory flat; sort names descending for recent work. Do not add date prefixes
to the files inside.

Archived means no longer active, not necessarily implemented or merged. Read
the recorded outcome and validation; use task records and Git/PR history for
delivery. Preserve historical records rather than updating them to match
current code.

This README is not a work item.
