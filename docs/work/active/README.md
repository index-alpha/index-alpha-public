# Active work

Read the [work protocol](../README.md) before planning or executing work.

Use `<task-ref>_<slug>/`, or `<slug>/` without a filesystem-safe task ID.
Task references are optional and can come from any work-tracking tool. Keep
related documents in one folder and create only the documents needed.

All new internal work documents start here, including audits, analyses,
proposals, and designs. Keep them here during review, even after drafting or
validation is complete. Only the user can confirm completion or direct stopping,
deferral, or archiving; agents must not make that decision themselves.

Keep implementation validation in the main plan. Record blockers, material
deviations, and the user's eventual disposition there.

This README is not a work item.
