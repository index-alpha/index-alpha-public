# Inbox

Read the [work protocol](../README.md) before adding or processing a handoff.

Use `YYYY-MM-DD_<source>_<slug>/handoff.md`; the date belongs to the folder.
Include source, the analyzed commit for code findings, evidence, and requested
action as specified in the protocol.
When available, include an optional `task_ref` ID or link from any work-tracking
tool; an external task is not required.

Intake is not authorization to implement. The receiving squad triages findings.
Move accepted items to `active/` or attach them to existing work; do not leave
duplicate copies. Archive useful no-action decisions with a short reason.

This README is not a work item.
