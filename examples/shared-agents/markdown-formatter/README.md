# Markdown formatter

Workflow rules version: `4`.

Apply the shared standard while preserving meaning, evidence, quotations, code
and managed images.

## Inputs and workflow

Supply account/eligible actor, exact Index/card targets, brief/version, invocation
deadline and explicit style overrides if any. Inherit mode from
[common rules](../../workflow.md). Read platform state first and pass results in
memory; optional `state_dir` holds only non-observable receipts or scratch files.
Authorized MCP page and evaluation tools suffice; no source research or installed packages.

1. Read [shared conventions](../README.md), the brief, [style.md](style.md) and
   [completion preflight](../completion.md).
2. Run [format.md](format.md) for changed Markdown/style scope, default five pages.
   A primary source-check timestamp alone does not require formatting again.
3. In edit mode, commit useful formatting changes; compliant no-change checks
   create an evaluation under [completion.md](../completion.md). Reuse proven
   matching coverage. Return linked changed/compliant/already-checked/proposed/
   blocked outcomes and saved evaluation IDs where applicable. Report mode
   returns unsaved proposals only.

Explicit Index overrides replace default choices; preservation rules still apply.
Version tags identify changed rules. If platform evidence does not identify prior
style/scope or a no-change outcome, use an optional matching receipt or simply
perform the bounded check. No mandatory local checkpoint or Agent-local store.

## Boundaries

Use the [maintained skill](../../../skills/index-alpha/SKILL.md). Remove identifiable
legacy administrative footers during authorized page edits under completion.md;
preserve article references and credits. Evaluations do not reopen formatting. No
fact-checking, metadata/ranking edits, new cards, image replacement or jobs. Report changes that would alter meaning. Host owns
maintenance-cycle completion and any small non-observable receipt.
