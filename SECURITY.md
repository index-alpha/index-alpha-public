# Security reporting

Do not put vulnerabilities, credentials, access tokens, cookies, authorization links, private Index content, or exploit details in a public issue.

Report vulnerabilities privately to [security@indexalpha.com](mailto:security@indexalpha.com).
This is the security contact published by the Index Alpha website and its Agent
notice. Use it while this repository is private and as the fallback contact after
publication. Do not send security reports through ordinary public issues.

After the approved public launch, maintainers must enable GitHub private
vulnerability reporting and verify the **Report a vulnerability** path before
announcing the repository. Once enabled, use **Report a vulnerability** on the
[Security advisories page](https://github.com/index-alpha/index-alpha-public/security/advisories)
or the email above. The [release checklist](docs/releasing.md) defines the launch sequence.

Include the affected resource or commit, the minimum steps needed to reproduce, observed impact, and a sanitized proof. Avoid accessing another person's account or content when gathering evidence. No response-time or bounty commitment is implied by this document.

For ordinary bugs and feature requests, use the [issue forms](https://github.com/index-alpha/index-alpha-public/issues/new/choose).
